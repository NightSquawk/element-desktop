# Feature Research

This folder is for structured research on Matrix clients, Element forks, adjacent collaboration tools, and supporting services that could influence the NightSquawk desktop client roadmap.

Use `METHODOLOGY.md` for the required format. Research belongs here when it compares external products, protocols, integrations, or deployment models. Implementation plans belong in `docs/todo/`.

Suggested first research topics:

- Element Desktop / Element Web upstream branding and packaging model
- Element Call and MatrixRTC client behavior
- Cinny, FluffyChat, SchildiChat, Hydrogen, and other Matrix clients
- Integration managers and widget catalogs
- Desktop auto-update and code-signing approaches for Electron apps
